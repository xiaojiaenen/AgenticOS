## 五、问题清单

### P1|功能 Bug:网站预览在开发环境跨域空白
前端 :3001 打开网站产物预览,iframe 被 "Blocked a frame with origin http://localhost:3001 from accessing a cross-origin frame" 拦截,预览区空白。磁盘上的产物本身正确(index.html + dist 完整)。生产 nginx 同源部署可能不受影响,但 dev 体验受损。建议:预览内容经前端同源代理(`/api/...` 转发或 vite proxy)提供。

### P2|行为问题:PPT 模式在 deepseek-flash 下跑偏
2 页极简 PPT 请求触发了 9+ 次文件系统探索(列目录、读 backend 源码、读 charts SVG、搜记忆),未进入 pptdeck 输出,人工停止。与 website 模式对比(同一模型表现良好),PPT 的 system prompt/工具集对推理型模型的引导不足;且每次文件访问都要审批,碎审批放大了摩擦。建议:收紧 PPT profile 的工具白名单、在 prompt 中明确"直接输出 pptdeck 代码块"、或为文件类工具在 PPT 模式默认免审批。

### P3|口径疑点:集成市场"暂无可用集成" vs 集成管理"8 个已发布"
admin 集成管理页显示 8 个集成全部"已发布",普通用户的集成市场却显示"管理员尚未发布任何集成"。若为按 profile/范围过滤的有意设计,建议空态文案说明原因;否则是发布状态字段两处读取不一致。

### P3|环境限制:UI 注册依赖邮箱验证码,未配 SMTP 时不可用
注册页仅提供验证码注册,`NOTIFY_SMTP_*` 未配置时点"发送验证码"报"系统邮箱未配置"。开发环境建议增加 dev 旁路(如 APP_ENV=test 时验证码写日志或固定码)。
