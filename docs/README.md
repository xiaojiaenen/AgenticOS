# 文档索引

AgenticOS 的文档按**用途**分目录存放。根目录只保留 `字体说明.md`（前端字体的操作步骤，
属日常参考资料，不是设计文档）。

| 目录 | 放什么 | 特征 |
|---|---|---|
| `design/` | 设计方案 | 已落地的技术设计，含架构决策与实施路径 |
| `research/` | 调研报告 | 对外做功课的结论：竞品、第三方库、方案对比 |
| `plans/` | 计划与路线 | 路线图、开发计划、阶段复盘 |
| `reports/` | 测试与实测报告 | 某个时点的实际运行结论 |
| `upstream/` | 上游相关 | 第三方框架的问题清单（供反馈给上游用） |
| `deploy/` | 部署参考 | 内网/离线环境部署的依赖与步骤 |

## 约定

- **报告类文档带日期或时点**（如 `测试报告-2026-10-01.md`）。它们记录的是**某一刻的
  事实**，不会自动更新 —— 读的时候注意时效，不要当成现状描述。
- **设计类文档是活文档**。若实现已经和文档对不上，以代码为准，并回头改文档。
- 文档之间的引用统一写成仓库根相对路径（如 `docs/design/m6-design.md`），
  这样从任意位置打开都能定位。
