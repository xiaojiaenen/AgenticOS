## 二、已确认的关键决策（Decisions，来自仓库文档）

`docs/development-plan-v2.md`（2026-09-30 定稿）中记录为「已确认决策」的 5 条：

1. 前端组件全量替换为 **shadcn/ui**，**不保留**现有样式与色板，删除玻璃拟态；
2. **Chrome 85 优雅降级**（新浏览器完整样式，85 不残缺）；
3. 生产数据库为 **MySQL**（不引入 PostgreSQL）；
4. 原计划第 3.1 节「自研轮子替换」**全部落地**；
5. `agent_service` 拆分 / `alembic` 引入 / `tsconfig strict` 纳入本计划。

其中第 4 条派生的具体技术选型（第二部分表格）与第 3 条共同约束了后半年的技术栈，属已锁定的下游决策：

- 登录限流 → **Redis 原子 INCR 固定窗口**（MySQL 状态机废弃；Redis 因此变为**生产必选依赖**）
- 前端 sanitize → **DOMPurify**（替换手写正则）
- `svg_editor` Flask 旁路 → **FastAPI APIRouter**（删除 Flask 依赖）
- 知识库检索 → **jieba 分词 + MySQL FULLTEXT `WITH PARSER ngram`**（淘汰 Python 内存 BM25）
- SSE 客户端 → **`@microsoft/fetch-event-source`**
