# Wrapped 年度报告 · 模板图生成提示词与艺术字规范

> 目标：用 GPT Image（项目生图技能为 `gpt-image-2.5`，与 "2.6" 同族）生成一套
> 风格统一的年度报告**模板底图**，动态数据（数字/姓名/年份）由前端用艺术字叠加。
> 依据：`gpt-image-2-5` 技能 `references/prompting-guide.md`（源自 OpenAI 官方
> 图像提示词指南）+ 公开 GPT Image 能力调研。

---

## 一、能力与提示词规范（调研结论）

### 模型能力
- **原生文字渲染**：能在图内渲染准确可读文字（海报/Logo/UI），但**密集排版、长段落
  仍建议生成底图后在代码/设计工具里排**——年度报告数据是动态的，必须走这条路。
- **强指令遵循**：适合「五段式」结构化简报，而非堆形容词。
- **编辑/多图融合**：`edit` 可做增量修改与多参考融合，迭代时优先 edit 而非重生成。
- **透明背景**：`--background transparent` + png，适合徽章/奖杯等独立资产。
- **风格 versatility**：摄影/插画/扁平/等距 3D/像素均可，给明确锚点即可。

### 提示词规范（必须遵守）
1. **五段式**：用途 → 主体 → 构图 → 风格与灯光 → 约束。替代形容词堆砌。
2. **具体可测试**：材质、颜色、数量、位置写清；主观词（高级/豪华）翻译成可见属性。
3. **正向描述**：只说想要什么，不用否定句（"无文字" 改为 "画面纯净、留白充足"，
   但模板底图确实需要排除文字时，用约束段明确 "画面不包含任何文字与字母"）。
4. **文字要渲染时**用引号原文 + 注明语言/字体 + "只出现一次、无其他文字"。
   **本报告底图不渲染文字**（数据动态叠加），故约束段统一声明不含文字。
5. **参数不进提示词**：size/quality/background/model 用 API 参数设置。
6. **风格锚点统一**：整套图复用同一段风格描述，保证跨卡片一致（同多帧一致性原则）。
7. **先草稿后成片**：先 `flare`/`medium` 验证方向，再 `sunburst`/`high` 精修。

### 推荐参数
- 竖版海报/手机分享：`1024x1536`；横版 Banner/底图：`1536x1024`；方形资产：`1024x1024`。
- 质量：探索 `medium`，交付 `high`。模型：探索 `gpt-image-2.5-flare`，交付 `gpt-image-2.5-sunburst`。
- 第三方代理若只支持标准三尺寸，退回 `1024x1024/1536x1024/1024x1536`。

## 二、全局风格锚点（每张图都复用，保证一致）

> 现代流媒体年度回顾（Spotify Wrapped 式）视觉：深墨蓝黑底（#0a0a12），
> 高饱和靛紫→品红极光渐变，半透明玻璃质感的漂浮 3D 缎带与光斑，细腻噪点颗粒，
> 边缘柔和辉光，庆祝感但克制、不杂乱；等距 3D 渲染 + 编辑插画混合风格，
> 影棚级柔光，左上方主光源。

把这段原样附加到下面每条提示词的「风格与灯光」段，勿逐张换措辞。

## 四、动态数据的字体与艺术字规范

数据（姓名/年份/数字）**不**烧进图片，由前端叠加，保证每人每年不同。

### 字体
- 中文：项目已内置 **HarmonyOS Sans SC**（`public/fonts/`，离线可用，免费商用），
  不引外网 CDN。当前内置 400/500 子集；要真·重字重艺术字，补充
  `HarmonyOS_Sans_SC_Bold/Black.woff2` 子集并在 `harmonyos-sans-sc.css` 增加
  `@font-face`（font-weight:700/900），否则 900 为合成加粗。
- 数字：展示级用 `.wrapped-display`（鸿蒙黑体 900 + 紧字距 + `tabular-nums`），
  比默认等宽更有海报感；密集表格仍用等宽保持可扫描。

### 艺术字（已实现，见 `index.css`）
- `.wrapped-display`：重字重展示字体。
- `.wrapped-art`：白→靛→品红渐变文字（`background-clip:text`），用于 Hero 标题。
- `.wrapped-art-warm`：金→珊瑚→品红渐变，用于结尾结语。
- 已应用于 `pages/Wrapped.tsx` 的 Hero 标题、年度称号、统计大数字、结尾结语。

### 叠加原则
- 底图留白区足够暗 → 白/渐变文字对比达标（≥4.5:1）。
- 数字用 `tabular-nums` 防跳动；大数字可加轻微 `text-shadow` 提升在纹理上的可读性。
- 导出分享图时如需把动态文字烧进图片，用前端 canvas/html-to-image 截图，而非让模型渲染数字。
