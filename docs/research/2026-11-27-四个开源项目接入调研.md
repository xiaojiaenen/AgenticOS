# 四个开源项目接入调研（2026-11-27）

针对 `kubai-icons` / `modern-web-guidance` / `ForesightJS` / `canvas-ui` 的 GitHub 调研与 AgenticOS 接入可行性评估。

## 总览结论

| 项目 | 是什么 | 许可证 | 结论 |
|---|---|---|---|
| kubai-icons | 4800+ 动画图标库 + Agent 画图 Skill | 图标/包 MIT；Skill source-available；网站保留权利 | ❌ 不整体引入，少量场景可选 |
| modern-web-guidance | 给 coding agent 的 web 平台 skill + CLI（Google/Edge/Mozilla/MDN） | Apache-2.0 / 文档 CC-BY 4.0 | ❌ 与 Chrome 85 硬约束冲突，暂不接入 |
| ForesightJS | 预测用户下一步点击、提前预取资源的库 | MIT | ✅ 值得小规模 PoC（后台重面板 chunk 预取） |
| canvas-ui | 多个同名项目：WebGL 特效库 / Canvas UI 渲染器 / AI 画布模板 | 混杂（MIT+Commons Clause / MIT / 无 LICENSE） | ❌ 不替换现有画布，可借鉴 2 个交互设计 |

## 1. kubai-icons

- 仓库：https://github.com/kubai087/kubai-icons （官网 icons.kubai.design，约 620★）
- 三合一：Agent 图标生成 Skill + 4800+ 图标库 + 网站。三种风格（Layered 带 hover 物理动画 / Two-tone solid / Line），React/Vue/WebComponent/静态 SVG 全支持，`kubai-icons-react@0.16.0` peer React>=18、TS 原生、tree-shakable、sideEffects=false。
- **许可证**：图标和四个 npm 包是 **MIT**（可商用）；Skill 本体是 Kubai Icons License（不得改版再分发）；Kubai 名称与 Logo 不可复用。
- Chrome 85：颜色用 JS 计算 hex/rgb，渐变/阴影用 SVG filter，未发现 oklch/color-mix，基本兼容；引入前跑 `npm run verify:css`。
- **判断**：本项目已有 lucide-react（122 个文件）+ hugeicons + 自研猫头鹰吉祥物/Logo/空状态体系，风格高度重复。技术接入无障碍但必要性低。
  - ✅ 可用场景：空状态焦点插画、功能上新提示、营销位等少量场景按需 `kubai-icons-react` 或静态 SVG；Skill 作为未来定制图标工具备选。
  - ❌ 不建议：替换 lucide 工具图标、替换品牌资产、大批量带动画图标。

## 2. modern-web-guidance

- 仓库：https://github.com/GoogleChrome/modern-web-guidance （26663★）+ `-src`；文档 developer.chrome.com/docs/modern-web-guidance
- 定位：面向 coding agent 的 **skill 包 + CLI**（非运行库），本地 embedding+BM25 检索 269 个 web 特性/206 用例的指南注入上下文。Apache-2.0 / 文档 CC-BY 4.0，维护活跃。
- **决定性冲突**：其 CSS Layout 章节明确推荐 oklch/color-mix，以及 View Transitions、Popover、Anchor Positioning、:has()、container queries 等 Chrome 111+/120+ API。本项目 **Chrome 85 底线 + `verify-css.mjs` 硬禁 oklch/color-mix**，整体接入等于给 agent 注入相反建议。
- **判断**：暂不整体接入。若未来抬升浏览器基线，天然入口是 `.agents/skills/`；现在最多手工摘取 Chrome 85 安全的无障碍/性能条目作为 AGENTS.md 极小补充并标注禁用项。`legacy-scan` 可零安装试用但结果需人工过滤。

## 3. ForesightJS ⭐ 唯一值得试点

- 仓库：https://github.com/spaansba/ForesightJS （1967★，MIT，2026-11 仍活跃）
- 定位：预测用户下一步点击（鼠标轨迹提前 ~120ms / Tab 提前 2 个 / 滚动方向），**只解决"何时预取"**，预取内容与方式由应用回调决定。全量 39KB min / 13KB gzip，按设备 code splitting（常驻 core ~17KB gzip）。
- React：`@foresightjs/react` 的 `useForesight` / `<Foresight>`，peer React 18/19，TS 完整；BrowserRouter 需在回调里自己 `import()` / `queryClient.fetchQuery()`。
- **适合场景（按价值）**：
  1. **后台 ~25 个 lazy 面板 chunk 预取**（含 recharts/Univer 1.7MB），鼠标移向菜单即 `import()` 对应面板，降低 Suspense 停顿 —— 最高价值。
  2. 路由级 chunk 预取（把 lazy loader 抽成具名函数复用）。
  3. 会话消息预取（Sidebar 会话项 → `fetchQuery(['session',id])`），需确认服务端带宽/审计可接受。
- **约束**：回调严格幂等（只 `import()`/`fetchQuery`），禁副作用；`trajectoryPredictionTime` 保守设 ~80ms，不放大 hitSlop；触屏收益低可关；敏感 admin API（聊天正文/ACL/审计）不做无差别预取。
- **风险空白**：核心依赖 `position-observer` 对旧版 IntersectionObserver 行为有依赖，Chrome 85 需实测再全量。
- **建议 PoC**：仅对 2–3 个高频重面板（知识库/用户分析/网关）接 `useForesight` + 1 处会话预取，配 devtools 观察 1–2 周命中率再定。

## 4. canvas-ui

同名多个，无一值得整体接入：
- DavidHDev/canvas-ui（5600★，MIT+Commons Clause）：WebGL/GLSL shader 特效组件库（Liquid/Glass 等），与节点式 AI 画布正交；可商用内嵌但不可单独再分发。
- alibaba/canvas-ui（232★，MIT）：Canvas 上的 DOM 式 UI 渲染器，无节点编辑/图生图。
- kyh/ai-canvas（41★，package.json 写 MIT 但**仓库无 LICENSE 文件**）：Next.js+eve+Konva 完整 AI 画布模板，功能最像本项目 /canvas（无限画布、Konva、AI 生图、每轮带画布快照+JSON 上下文）。
- Flowscape-UI/canvas-react（Apache-2.0）：无限画布节点库，Edit Frame 浮层（四角缩放 Shift 锁比例/Alt 中心缩放、旋转手柄、尺寸徽标、一次手势一次 history）。

本项目现状：`CreativeCanvas.tsx` ~1777 行自研（@xyflow/react + Dagre + Zundo + react-konva 蒙版），后端 `/canvas/generate`（文生图/图生图）+ `/process`（Pillow）+ 鉴权/额度/产物体系完整。
- **判断**：保持自研画布，不引入任何名为 canvas-ui 的库。
- **可借鉴（约 200–400 行改动）**：
  1. Flowscape 的 **Edit Frame 手势**（给选中节点加缩放/旋转手柄、尺寸徽标，拖拽临时更新、松手一次提交兼容 Zundo）——Apache-2.0 可安全借鉴。
  2. kyh/ai-canvas 的**画布快照 + 上下文喂给生图模型**交互、生成中 spinner 占位节点 —— 只借鉴设计不复制代码（无 LICENSE）。
  3. WebGL 特效组件优先级低（重依赖 + Commons Clause + 与克制设计冲突）。
