# 字体说明

AgenticOS 的字体策略：**中文用鸿蒙 HarmonyOS Sans，西文用等宽（JetBrains Mono）**。

## 为什么西文用等宽

产品定位是企业内部的工程/运维工具平台，等宽字形让数字、ID、路径、命令、日志
对齐可读——这恰好是这类界面里最高频出现的内容。相比几何无衬线（Plus Jakarta
Sans 之类），等宽在密集信息场景下更"可扫描"。

## 字体从哪里来

项目**不引外网字体 CDN**（内网部署时 Google Fonts 不可达会拖慢首屏并出现
FOUT）。字体文件按需自备，放在 `public/fonts/`：

```
public/fonts/
├── harmonyos-sans-sc.css        # 鸿蒙 @font-face 声明（引用下面的分片）
├── Regular_<hash>.woff2 × ~120  # 鸿蒙 常规，按 unicode-range 分片
├── Medium_<hash>.woff2  × ~20   # 鸿蒙 中等（500）
├── Bold_<hash>.woff2    × ~20   # 鸿蒙 粗体（600/700）
├── JetBrainsMono-400.woff2      # 等宽 常规
└── JetBrainsMono-500.woff2      # 等宽 中等（500/600）
```

鸿蒙字库按 unicode-range 切成上百个分片，浏览器只会下载当前页面真正用到字符所在
的那几片；整包约 10MB 的 SC 全量字库如果一次性加载，内网首屏会明显变慢。

### 获取方式

- **HarmonyOS Sans（鸿蒙）**：华为官方免费商用字体，从华为开发者官网下载
  （[HarmonyOS Sans 下载页](https://developer.huawei.com/consumer/cn/design/harmonyos-font/)），
  解压后取 `HarmonyOS_Sans_SC_*.ttf`，再用 `pyftsubset` 按 unicode-range 切片：

  ```bash
  pyftsubset HarmonyOS_Sans_SC_Regular.ttf --flavor=woff2 \
    --unicodes-file=subsets.txt --output-file=Regular_<hash>.woff2
  ```

  再把生成的 `@font-face` 块汇总进 `harmonyos-sans-sc.css`（每片一条
  `unicode-range` 声明）。仓库里已包含切好的成品，**不需要重新生成**。
- **JetBrains Mono**：JetBrains 官网免费开源（OFL 协议），
  [下载](https://www.jetbrains.com/lp/mono/)。

> HarmonyOS Sans 需遵守其随包附带的授权协议（允许商用，但不得单独售卖字体本身）。

**没放字体文件也能正常用**：`@font-face` 先走 `local()`（用户机器装了鸿蒙/装了
JetBrains Mono 就会自动生效），再逐级回退：

```
中文 → PingFang SC（macOS）→ 微软雅黑（Windows）→ Noto Sans CJK
西文 → 系统 ui-monospace / Menlo / Consolas
```

不会出现方框字。

> 注意：`@font-face` 里**只写实际存在的文件**。写一个不存在的路径不会静默失败——
> 浏览器会拿到 SPA 兜底返回的 HTML，在控制台刷
> `OTS parsing error: invalid sfntVersion` 并每次重新请求。

## 代码位置

- 鸿蒙分片声明：`public/fonts/harmonyos-sans-sc.css`（在 `src/index.css` 顶部 `@import`）
- 等宽字体声明与回退栈：`src/index.css` 顶部 `@font-face` + `@theme` 的
  `--font-sans` / `--font-mono` / `--font-display`
- `--font-display`（原先的标题字体 Space Grotesk）已并入 `--font-sans`，
  标题与正文使用同一字体栈，避免"标题一种字体、正文另一种"的割裂感

## 微调

若某处需要纯中文或纯等宽，用 Tailwind 工具类即可：

- `font-mono`：强制等宽（代码块、ID、表格数字列常用）
- `font-sans`：跟随全局字体栈
