透明加密上传诊断

在本机浏览器里直接读文件，判断 DLP 是否把浏览器加了白名单。全程本地运行，不上传任何内容。

第一步：浏览器读到的到底是什么

把 xlsx / docx / pptx / pdf 拖到这里，或点击选择文件
建议用真实业务文件（排班表、报表、合同），不要用新建的空文件

第二步：传到服务端后是什么（可选）

填你的平台上传地址。若第一步是明文、这一步变密文，说明是网络侧 DLP 在动上传报文。 不填则跳过。

判定依据

文件头含义
50 4B 03 04OOXML 明文 — xlsx / docx / pptx
D0 CF 11 E0OLE2 明文 — xls / doc / ppt
25 50 44 46PDF 明文
其他 16 字节密文 — 浏览器不在白名单，或文件本身被加密

注意：有的 DLP 不加密文件头，只加密正文，或把密文放进备用数据流（ADS）。 所以还要看「浏览器读到的大小」是否等于「资源管理器显示的大小」——被加密的文件常按 512/1024 字节对齐，大小会变。
