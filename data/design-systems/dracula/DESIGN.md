## 1. Visual Theme & Atmosphere

The iconic purple dark theme that conquered code editors. Deep eggplant canvas (`#282a36`) with electric lavender, hot pink, and cyan accents. Dark enough for readability, colorful enough for personality. Cards float above the background with subtle contrast — never pure black, always warm-tinted dark. Shadows are unnecessary; color contrast alone defines depth.

**Mood:** Creative, developer-friendly, bold but refined.
**Best for:** Developer tools, API presentations, creative tech, design systems, hackathons.

## 3. Typography

- **Display:** Inter or system sans-serif, 700 weight, text-1 or accent
- **Body:** 400 weight, text-2, 18-24px
- **Code:** JetBrains Mono or Fira Code, 14-16px, green or cyan
- All text on dark — no reversed type needed

## 4. Prompt Guide

- Purple (`--accent`) is the hero color — use it for headlines and CTAs
- Pink (`--accent-2`) for secondary emphasis, cyan (`--accent-3`) for links/hover
- Code blocks look great on `--surface-2` with green syntax coloring
- Avoid blue-dominant layouts — let purple/pink/cyan carry the energy
