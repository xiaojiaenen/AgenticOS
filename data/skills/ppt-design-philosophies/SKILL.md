# PPT 设计哲学库

在策略师阶段，从以下 5 大流派中选择最匹配用户需求的风格。每个风格决定了 deck 的视觉语言、配色倾向、字体选择和布局节奏。

---

## 一、信息建筑流派（Information Architecture）

核心理念：**信息即结构，结构即美感**。用严谨的网格和层次让复杂信息一目了然。

### 1.1 Pentagram 风格
- **理念**：网格即秩序，留白即呼吸
- **视觉特征**：严格 12 列网格、大量留白、文字主导、极少装饰
- **配色**：黑白灰为主，单一强调色（红/蓝）
- **字体**：标题用衬线体（Playfair Display），正文用无衬线（Inter）
- **适用**：投资人报告、战略提案、年度总结
- **节奏**：anchor 为主，dense 少用，强调结构感

### 1.2 数据驱动风格
- **理念**：数据说话，图表即叙事
- **视觉特征**：大数字突出、图表密集、信息密度高
- **配色**：深色背景 + 高对比度数据色
- **字体**：等宽字体用于数据（JetBrains Mono），无衬线用于标题
- **适用**：季度财报、数据分析、运营报告
- **节奏**：dense 为主，穿插 breathing 做数据冲击

## 二、动效诗歌流派（Motion Poetics）

核心理念：**运动即叙事，节奏即情感**。用动态视觉讲故事。

### 2.1 全屏视觉冲击风格
- **理念**：一屏一世界，每个画面都是海报
- **视觉特征**：全出血图片/渐变背景、超大标题、极简信息
- **配色**：大胆渐变、高饱和度
- **字体**：超粗无衬线（800-900 weight）
- **适用**：产品发布、品牌宣传、创意提案
- **节奏**：anchor + breathing 交替，制造呼吸感

### 2.2 滚动叙事风格
- **理念**：像杂志一样阅读，每页一个故事节点
- **视觉特征**：左图右文/上图下文交替、故事线清晰
- **配色**：温暖中性色 + 一个品牌强调色
- **字体**：衬线标题 + 无衬线正文
- **适用**：用户研究、品牌故事、案例分析
- **节奏**：dense + breathing 交替，模拟阅读节奏

---

## 三、极简主义流派（Minimalism）

核心理念：**少即是多，去除一切不必要**。

### 3.1 瑞士国际风格
- **理念**：网格、无衬线、客观排版
- **视觉特征**：严格网格对齐、无圆角、无阴影、1px 边框
- **配色**：黑白灰 + 单一高饱和强调色
- **字体**：纯无衬线（Inter Tight / Helvetica）
- **适用**：技术报告、AI 提案、开发者大会
- **特殊约束**：所有 rx=0，禁止阴影/渐变/模糊

### 3.2 日式留白风格
- **理念**：留白是设计的一部分，不是空白
- **视觉特征**：大量留白、文字居中、元素极少
- **配色**：浅灰/米白背景 + 深色文字
- **字体**：细体无衬线（300-400 weight）
- **适用**：学术报告、冥想/正念、高端品牌
- **节奏**：几乎全是 breathing，anchor 做结构断点

### 3.3 杂志排版风格
- **理念**：像翻开一本精致杂志
- **视觉特征**：大标题 + 小正文的极端对比、分栏排版
- **配色**：黑白为主 + 单页一个彩色元素
- **字体**：展示衬线（Playfair Display）+ 正文无衬线
- **适用**：年度报告、深度分析、人物专访

---

## 四、实验先锋流派（Experimental Avant-garde）

核心理念：**打破常规，用视觉实验挑战认知**。

### 4.1 赛博朋克风格
- **理念**：科技感 + 未来感 + 暗色美学
- **视觉特征**：深色背景、霓虹色点缀、网格线/代码元素
- **配色**：深蓝/黑背景 + 霓虹绿/粉/蓝
- **字体**：等宽字体（JetBrains Mono）+ 粗无衬线
- **适用**：技术分享、开发者大会、安全报告

### 4.2 生成艺术风格
- **理念**：代码生成的图案即装饰
- **视觉特征**：几何图案背景、粒子效果、数据可视化装饰
- **配色**：黑白 + 一个算法生成的渐变色
- **字体**：等宽字体为主
- **适用**：AI/ML 技术报告、数据科学、创意编程展示

### 4.3 大胆宣言风格
- **理念**：态度即设计，视觉即立场
- **视觉特征**：超大文字、不对称布局、撞色搭配
- **配色**：高对比度撞色（红+黑、黄+蓝）
- **字体**：超粗无衬线（900 weight）
- **适用**：品牌发布会、创意提案、招聘宣传

---

## 五、东方哲学流派（Eastern Philosophy）

核心理念：**不完美之美，功能即形式**。

### 5.1 侘寂风格（Wabi-sabi）
- **理念**：不完美、不恒久、不完整之美
- **视觉特征**：手绘质感、不规则边缘、自然材质纹理
- **配色**：大地色系（棕/灰/米/褐）
- **字体**：手写风格衬线 + 素雅无衬线
- **适用**：品牌故事、手工艺、文化类报告

### 5.2 无印良品风格（MUJI）
- **理念**：去掉品牌标记，回归功能本质
- **视觉特征**：极简功能排版、无装饰、信息层次清晰
- **配色**：白/米/灰，几乎无彩色
- **字体**：细体无衬线（300 weight）
- **适用**：产品说明、内部汇报、流程文档

### 5.3 中国水墨风格
- **理念**：留白即意境，笔触即情感
- **视觉特征**：水墨渐变背景、书法标题、留白大量
- **配色**：黑白灰水墨色 + 一个朱红点缀
- **字体**：书法风格标题 + 宋体/黑体正文
- **适用**：文化类演讲、传统品牌、中式美学

## 风格选择决策树

```
用户需求 →
├── 数据密集？→ 数据驱动 / Pentagram
├── 品牌宣传？→ 全屏视觉冲击 / 大胆宣言
├── 技术分享？→ 赛博朋克 / 瑞士国际
├── 学术报告？→ 日式留白 / Pentagram
├── 文化类？→ 中国水墨 / 侘寂
├── 产品发布？→ 全屏视觉冲击 / 生成艺术
├── 内部汇报？→ 无印良品 / 杂志排版
└── 不确定？→ Pentagram（最安全的选择）
```

## 与 spec_lock 的关系

选定风格后，将风格的视觉特征融入 spec_lock：
- 配色方案从风格的推荐色中选取
- 字体组合从风格的推荐字体中选取
- 页面节奏标签参考风格的节奏建议
- 布局选择参考风格的典型布局模式
