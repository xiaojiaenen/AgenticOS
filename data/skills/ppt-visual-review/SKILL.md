# PPT 视觉审查 Rubric

PPT 生成完成后，按以下规则逐页审查。

---

## 硬规则（必须修复，否则不合格）

| 编号 | 规则 | 检查方法 |
|------|------|---------|
| H1 | 内容超出画布边界 | 检查所有元素坐标是否在 viewBox 范围内 |
| H2 | 文字溢出容器 | 文字宽度是否超出父容器 rect 宽度 |
| H3 | 文字重叠 | 两个 text 元素的 bounding box 是否相交 |
| H4 | 可读性 | 文字与背景对比度 ≥ 4.5:1（大字 ≥ 3:1） |
| H5 | 元素碰撞 | 卡片/图标/文字是否互相遮挡 |
| H6 | 锚定元素位移 | 固定位置元素（页码/页脚）是否偏移 |
| H7 | 图片渲染异常 | image 元素是否缺失 href 或 dimensions |
| H8 | 缺少关键元素 | 每页是否有标题、内容、notes |

## 软规则（建议修复）

| 编号 | 规则 | 检查方法 |
|------|------|---------|
| S1 | 垂直节奏均匀 | 相邻元素间距差异不超过 ±30% |
| S2 | 视觉重心合理 | 主要内容不在画布角落 |
| S3 | 对齐一致性 | 同级元素的 x/y 起点是否对齐 |
| S4 | 网格均匀性 | 卡片网格的间距是否一致 |
| S5 | CJK 字间距 | 中文文字无异常间距 |
| S6 | Accent 过度使用 | accent 色使用 ≤ 2 处 |
| S7 | 强调不一致 | 同级标题字号/字重是否统一 |
| S8 | 图文关系 | 图片与相关文字距离合理 |
| S9 | 呼吸违反 | dense 页后是否有 breathing 页 |

## 不触碰规则

审查时不要修改：
- 品牌决策（颜色/字体/主题选择）
- 页面布局结构
- 内容文本
- 其他页面的 SVG

## 审查流程

1. 用 `read_slide(N)` 读取每页 SVG
2. 逐页对照硬规则检查
3. 逐页对照软规则检查
4. 输出审查报告：

```
## 审查报告

### 第 1 页
- H1 ✅  H2 ✅  H3 ✅  H4 ✅  H5 ✅  H6 ✅  H7 ✅  H8 ✅
- S1 ⚠️ 标题与正文间距偏大（48px vs 建议 24px）
- S6 ✅

### 第 3 页
- H2 ⚠️ 标题文字可能溢出容器
- S3 ⚠️ 左侧卡片 x=60，右侧卡片 x=660，未居中对齐
```

5. 对 H 级问题，用 `save_slide` 修正后重新检查
