# PPT 专家评审

5 维度评分体系，每个维度 0-10 分。总分 = 加权平均。

---

## 评审维度

### 维度 1：设计哲学一致性（权重 25%）

检查 deck 是否贯彻了选定的设计风格。

| 分数 | 标准 |
|------|------|
| 9-10 | 每页都体现风格特征，无偏离 |
| 7-8 | 大部分页面一致，1-2 页有轻微偏离 |
| 5-6 | 风格不统一，不同页面像不同人做的 |
| 3-4 | 风格混乱，无法辨识设计语言 |
| 0-2 | 完全没有设计风格意识 |

检查项：
- 选定的风格特征是否在每页中体现？
- 配色/字体/布局是否与风格一致？
- 是否有页面偏离了整体视觉语言？

### 维度 2：视觉层次（权重 25%）

检查信息优先级是否清晰。

| 分数 | 标准 |
|------|------|
| 9-10 | 每页有一个明确的视觉入口，层次分明 |
| 7-8 | 层次基本清晰，个别页面略有模糊 |
| 5-6 | 多个元素争夺注意力，层次不明确 |
| 3-4 | 没有主次之分，信息平铺 |
| 0-2 | 完全无法分辨重点 |

检查项：
- 每页是否有且仅有一个主导元素？
- 标题/正文/标签的字号层级是否清晰？
- 视觉重心是否合理（不在角落）？

### 维度 3：工艺质量（权重 20%）

检查对齐、间距、字体层级等细节。

| 分数 | 标准 |
|------|------|
| 9-10 | 所有元素精确对齐，间距统一，细节完美 |
| 7-8 | 大部分对齐，个别偏差 ≤2px |
| 5-6 | 明显的对齐偏差和间距不一致 |
| 3-4 | 粗糙的排版，多处对齐问题 |
| 0-2 | 完全没有排版意识 |

检查项：
- 同级元素是否对齐？
- 间距系统是否统一（组内 8-16px，组间 32-64px）？
- 字体层级是否一致（同级标题相同字号/字重）？

### 维度 4：功能性（权重 20%）

检查信息传达是否有效。

| 分数 | 标准 |
|------|------|
| 9-10 | 信息传达精准，观众能立即理解核心观点 |
| 7-8 | 信息基本清晰，需要稍加思考 |
| 5-6 | 信息模糊，需要反复阅读 |
| 3-4 | 信息混乱，难以理解 |
| 0-2 | 完全无法传达信息 |

检查项：
- 每页的核心信息是否一句话能说清？
- 标题是否有观点（不是名词短语）？
- 数据是否有上下文（对比基准）？
- 演讲者备注是否补充了必要信息？

### 维度 5：原创性（权重 10%）

检查是否避免了 AI 生成的千篇一律。

| 分数 | 标准 |
|------|------|
| 9-10 | 有独特的设计语言，明显不同于典型 AI 输出 |
| 7-8 | 有一些独特的处理，但整体较常规 |
| 5-6 | 标准 AI 输出，没有明显的个性化 |
| 3-4 | 典型的 AI 生成痕迹（紫渐变/圆角卡片/emoji） |
| 0-2 | 完全是模板化输出 |

检查项：
- 是否避免了常见 AI 陷阱（见 anti-slop 检查器）？
- 布局是否有变化（不是每页相同结构）？
- 是否有独特的视觉处理（非标准排版/装饰）？

## 评审输出格式

```
## 专家评审报告

### 总分：X.X / 10

| 维度 | 分数 | 评语 |
|------|------|------|
| 设计哲学一致性 | X/10 | ... |
| 视觉层次 | X/10 | ... |
| 工艺质量 | X/10 | ... |
| 功能性 | X/10 | ... |
| 原创性 | X/10 | ... |

### 关键发现
1. [最重要的问题]
2. [第二重要的问题]
3. [第三重要的问题]

### 改进建议
1. [最高优先级改进]
2. [第二优先级改进]
3. [第三优先级改进]
```

## 评分参考

| 总分 | 等级 | 建议 |
|------|------|------|
| 8.5-10 | 优秀 | 可直接使用 |
| 7.0-8.4 | 良好 | 小幅优化后使用 |
| 5.0-6.9 | 合格 | 需要修订关键问题 |
| 3.0-4.9 | 不合格 | 建议重新设计 |
| 0-2.9 | 严重不合格 | 必须重做 |

## 不触碰规则

评审时不要修改：
- 品牌决策
- 页面布局结构
- 内容文本
- spec_lock 中的参数
