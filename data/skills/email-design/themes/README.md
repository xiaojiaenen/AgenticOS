# 邮件主题档案（Theme Profiles）

每个主题是一个**有性格的视觉方向**，不是「一套配色」这么简单。选主题 = 选择一种
「这封邮件想给人什么感觉」。主题之间刻意拉开家族，避免每次都像同一个模板。

## 档案格式

每个 `themes/<id>.md` 都写这几段：

- **气质（mood）**：一两句话，说这个主题什么感觉、像什么样的人写的。
- **适合 / 不适合**：明确边界，防止选错。
- **调色（palette）**：4–6 个命名色值，标注各自用途（底色/墨色/强调/分割/状态）。
- **排版（type）**：字号音阶（标题/正文/辅助）、字重、字体栈。
- **版式（layout）**：一句话布局描述 + ASCII 线框。
- **signature**：这个主题的记忆点是什么（唯一的高光元素）。
- **完整 HTML**：一份可直接改成内容的成品，全部内联样式、table 布局。
- **禁止项**：这个主题里最容易踩、会直接毁掉气质的几件事。

## 主题索引

| id | 气质 | 一句话记忆点 |
|---|---|---|
| `swiss` | 冷中性、网格、系统感 | 一条严格对齐的细线 + 大号近黑标题 |
| `press` | 书卷、温暖、编辑感 | 衬线大标题 + 双细线报头 |
| `terminal` | 暗底工程、等宽、克制 | 暗底 + 等宽数据 + 一枚状态色 |
| `quiet` | 极简留白、近乎无装饰 | 一个巨大的留白 + 一行字 |
| `warm` | 暖白 + 明黄、机灵有人味 | 明黄只作荧光笔/色块，绝不作文字色 |
| `datatable` | 数字优先、扫描友好 | 右对齐的数字列 + 涨跌标记 |
| `editorial` | 杂志式、大标题、图片位 | 大标题压图 / 引文块 |
| `tufte` | 数据墨水比、极简发丝线 | 大页边 + 一条贯穿发丝线，别无他物 |
| `bodoni` | 报刊 Didone 高反差 | 粗细双线刊头 + 极端字重对比大标题 + 首字下沉 |

## 选主题的 30 秒决策

1. 这封邮件是**事务**还是**表达**？
   - 事务（通知/汇报/汇报数据）→ `swiss` / `terminal` / `datatable` / `tufte`
   - 表达（介绍/邀请/感谢/长说明）→ `press` / `editorial` / `warm` / `bodoni`
   - 极短、一对一 → `quiet`
2. 收件人是**工程/技术**还是**其他**？技术且要"现场感" → `terminal`；否则不选深底。
3. 有**真数据**要对比吗？有 → `datatable`（带彩标）或 `tufte`（纯灰度、极致克制）。
4. 需要**温度/亲切**吗？需要且不强正式 → `warm`；要正式卷面感 → `press` / `bodoni`。
5. 要**最强辨识度**、不怕"有设计感"→ `bodoni`（报刊）或 `editorial`（杂志）。

选不定时，`swiss` 是最安全的通用选择（冷中性、不出错、也不抢戏）。
