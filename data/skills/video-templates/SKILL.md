# 视频模板库速查

23 个专业视频模板，按类别分组。

## 一、数据可视化（Data Viz）

### frame-data-chart-nyt
- **名称**：纽约时报风格数据图表
- **风格**：印刷社论风格，干净专业
- **适用**：数据报告、新闻可视化、商业演示
- **特点**：柱状图、折线图、饼图动画

### frame-nyt-graph
- **名称**：NYT 图表
- **风格**：纽约时报印刷风格
- **适用**：社论数据、研究展示
- **特点**：简洁的图表动画

### frame-pentagram-stat
- **名称**：瑞士网格统计锚点
- **风格**：瑞士国际主义风格
- **适用**：统计数据展示、KPI 仪表盘
- **特点**：网格布局、数字动画

### frame-data-rollup
- **名称**：数据滚动柱状图
- **风格**：现代数据可视化
- **适用**：数据对比、趋势展示
- **特点**：柱状图生长动画 + 数字滚动（Remotion 原生）

## 十、模板变量

每个模板都有自己的变量（inputs），使用 `video_get_template(template_id)` 查看详细信息。

### 常见变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `title` | string | 主标题 |
| `subtitle` | string | 副标题 |
| `caption` | string | 说明文字 |
| `data` | object | 数据内容 |
| `color` | string | 主题颜色 |
| `background` | string | 背景颜色 |
| `logo` | string | Logo URL |

### 使用示例

```python
video_set_variables(project_id, {
    "title": "2024 年度报告",
    "subtitle": "业绩增长 30%",
    "data": {"values": [10, 20, 30, 40, 50]},
    "color": "#00d4ff"
})
```
